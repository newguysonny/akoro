Plate 01 · the field

This background is math, running on your GPU.

A domain-warped noise field — fbm(p + fbm(p + fbm(p))) — computed per pixel, per frame. In late 2025, WebGPU shipped by default in Chrome, Edge, Safari 26 and Firefox, ending the fifteen-year WebGL era. This page compiles a WGSL pipeline first and falls back to a GLSL twin if it must. The field listens: it bends around your pointer, gains turbulence with your scroll velocity, and re-tunes its palette for every chapter.

Plate 03 · anchors, popovers, invokers

The tooltip library era is over.

Floating UI, Popper, and a decade of z-index archaeology existed to solve one problem: put a box next to a button without clipping. CSS anchor positioning — now in Chrome, Safari 26 and Firefox — solves it in four declarations, with automatic flipping when space runs out. Pair it with the popover attribute for top-layer stacking and commandfor for zero-script dialogs.

anchor-name / position-area popover commandfor appearance: base-select

Plate 05 · color science

Color finally left sRGB.

HSL lies about lightness: yellow at 50% screams, blue at 50% broods. OKLCH is perceptually uniform — same L, same perceived brightness — and with oklch(from …) relative syntax, whole design systems derive from one token. Plate 07 · motion

Interfaces stopped teleporting.

The View Transition API snapshots the page, lets the DOM change, then morphs between the two — the trick that once required FLIP libraries and a weekend. interpolate-size lets CSS animate to height: auto, the oldest unanswered question on Stack Overflow. And linear() easing encodes real spring physics as a plain timing function.

Waveform

Animating to auto at last

Why this was impossible
CSS could never interpolate between a length and auto — the end value was unknowable before layout. Every accordion you have ever shipped measured scrollHeight in JS.
What changed
interpolate-size: allow-keywords opts the page in, and ::details-content exposes the collapsing box. Two declarations replace the measurement dance. Bonus: name="fold" makes these exclusive natively.
The exit problem
transition-behavior: allow-discrete lets display and content-visibility wait for the animation to finish before flipping — which is why closing me is smooth too.

A spring, as an easing curve click the track

linear(0, 0.009, … 1.077 26.8%, … 1) — sampled spring physics, applied to a plain CSS transition. No rAF, no library, real overshoot.
