## Manage Periods

**Manage Periods** defines the day's shape: each class can have its own
daily periods, so open a class here to set its period times. Periods
are the slots the timetable fills.

## Class Timetable

The **Class Timetable** is the printed weekly timetable per class:
pick a class (and a section, or all sections) to view and edit which
subject sits in each period across the week.

## Weekly Forecast

The **Weekly Forecast** shows what will be taught each day for a class
and week. It follows the class timetable, turning slots into the week's
actual teaching plan.

## Daily Schedule

The **Daily Schedule** is a single day's plan, period by period, for a
class and date — the view to open each morning to see the day as it
will run.
