## Classes

**Classes** lists every class across every academic level, with its
sections, student count, and class teacher. **Add Class** creates one
under a level. Open a class to manage its **Sections** — the arms
(built from your [section types](/docs/school/academics/setup)) that
split a class into groups. The Class Sections page works on the class
you picked here.

![Classes: header and Add Class](/images/school/academics/classes.png)
*All classes, filterable by level and status.*

## Subjects

**Subjects** is the school's subject catalogue — each subject has a
name, a code, and a type: **Core** or **Elective**. **Add Subject**
extends the catalogue.

## Assign Subjects

**Assign Subjects** decides what each class is taught: choose a class,
then add subjects to it from your catalogue. **Assign Electives** does
the same for the elective subjects a class offers, which its students
then choose among.
