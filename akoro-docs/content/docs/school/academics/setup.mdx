## Academic Sessions

**Academic Sessions** are your school years and terms. Each session has
a start and end date, and one is marked **Active** — the session the
portal works in. **New Session** adds the next year before it begins,
so promotions, fees, and timetables can be prepared against it.

![Academic Sessions: the 2026/2027 session, active](/images/school/academics/sessions.png)
*Sessions with their dates; one is active at a time.*

## Academic Calendar

The **Academic Calendar** holds the key dates for each term —
resumption, vacation and term ends, holidays, mid-term breaks,
examinations, parent–teacher meetings, and other events. View it as a
calendar or a list, and add dates with **New Entry**, choosing the entry
type so the colour coding stays meaningful.

![The Academic Calendar's entry types](/images/school/academics/calendar.png)
*Every key date, typed and colour-coded.*

## Academic Levels

**Academic Levels** are the bands your classes sit in — each with a
code, a name, and an order, plus live counts of its classes and
students. **Add Academic Level** creates one; levels can be active or
inactive.

## Section Types

**Section Types** are reusable class arms — A, B, C, D — shared across
the school. Define them once here, and every class can use them for its
sections; the list shows how many sections use each type.
