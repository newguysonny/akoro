## Transport Dashboard

The **Transport Dashboard** puts the fleet at a glance: vehicles,
active vehicles, routes, and location reports.

![Transport Dashboard: fleet and routes at a glance](/images/school/transport-hostel/dashboard.png)
*Vehicles, routes, and the latest position reports.*

## Manage Vehicles

**Manage Vehicles** is the school fleet: each vehicle shows its plate
number, model, capacity, driver, and the driver's phone, with a
status of Active, Maintenance, or Retired. Filter by status, and add
to the fleet with **Add Vehicle**.

## Manage Routes

**Manage Routes** holds the pickup and drop-off routes the buses run.
**New Route** adds one, so each run has a defined path for drivers,
students, and parents to work from.

## Live Vehicle Tracking

**Live Vehicle Tracking** shows the latest reported position per
vehicle — where it was, when, and which run it was on, such as a
morning pickup run. Use **Report Position** to post a vehicle's
current location; the newest report is the one the dashboard counts
and this page shows.

![Live Vehicle Tracking: the latest position for each vehicle](/images/school/transport-hostel/tracking.png)
*One current position per vehicle, from its latest report.*
