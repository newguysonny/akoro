The Examination section runs assessment end to end. The Exam Dashboard
gives the offline examination overview; around it:

- [Exam setup](/docs/school/exams/exam-setup) — exam types, exam
  events, and the papers each class sits.
- [Marks & grades](/docs/school/exams/marks-and-grades) — entering
  scores and the grading scales, academic and cocurricular.
- [Report cards](/docs/school/exams/report-cards) — layouts,
  marksheets, teacher remarks, and the PINs parents check results
  with.
- [Online exams](/docs/school/exams/online-exams) — computer-based
  tests built from the question bank.

For continuous assessment inside the learning app itself, see
[Assessments & lesson review](/docs/school/learning/assessments-and-lesson-review);
for Kenya's CBC model, see the [CBC hub](/docs/school/cbc).
