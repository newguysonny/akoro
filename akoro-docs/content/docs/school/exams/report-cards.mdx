## Report Card Setups

**Report Card Setups** holds the report card layouts — what a report
card shows and how it is arranged. **New Setup** creates one; generated
results render through the setup you choose.

## Generate Marksheet

**Generate Marksheet** builds the class result matrix for an exam:
pick the exam and the class, and **Generate** — every student against
every paper, from the marks entered.

![Generate Marksheet: exam and class pickers](/images/school/exams/generate-marksheet.png)
*The result matrix for one class in one exam.*

## Upload Marksheet

Results prepared outside the portal can be attached instead:
**Upload Marksheet** takes a title, the exam, the class, a file URL,
and a note. **Manage Uploads** lists every uploaded marksheet.

## Teacher Remarks

**Teacher Remarks** holds per-student report card remarks, per exam.
**New Remark** writes one against a student, so the class teacher's
voice lands on the card next to the numbers.

## Result PINs

**Result PINs** are how parents see results: PINs are used on your
public website's **/results** checker. Generate them per exam, for one
class or the whole school, and set **Max checks** — how many times a
PIN can be used before it stops working.

![Result PINs: exam, class scope, and max checks](/images/school/exams/result-pins.png)
*Generate PINs per exam; a blank class means the whole school.*
