## Exam Types

**Exam Types** names the kinds of examination your school runs —
Mid-Term, End of Term, and your own under **New Type**. Every exam
event is one of these types.

## Manage Offline Exams

**Manage Offline Exams** lists the exam events: type, session, start
date, and status (Upcoming, Ongoing, Completed), filterable by status.
**New Exam** creates an event — for example, "First Term Mid-Term
2026" in the 2026/2027 session.

![Manage Offline Exams: the exam events list](/images/school/exams/offline-exams.png)
*Each event has a type, a session, a start, and a status.*

## Schedule & Marks Setup

**Schedule & Marks Setup** defines the papers: for an exam, class, and
subject, the paper that will be sat and marked. **New Schedule** adds a
paper. [Enter Marks](/docs/school/exams/marks-and-grades) works paper
by paper, so this setup is what makes marks entry possible.
