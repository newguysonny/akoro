## Attendance Register

The **Attendance Register** marks a whole class in one screen: pick a
class, narrow to a section (or all sections), and pick the date to take
attendance for that day.

## Student Attendance

**Student Attendance** is the same register reached the other way:
choose the class and section, set the date, and **Load Register** to
mark each student present or absent.

![Student Attendance: class, section, date, Load Register](/images/school/attendance/load-register.png)
*Load the register for a class and date, then mark it.*

Marked registers feed the Student Dashboard's present/absent counts for
the day, so take them in the morning — the dashboard is only as current
as the last register loaded.
