The Library section runs the school library: what the collection
holds, how it is organised, and what is out on loan. The **Library
Dashboard** sums it up — book titles, total copies, available copies,
books out, and categories.

![Library Dashboard: collection and loans at a glance](/images/school/library/dashboard.png)
*Titles, copies, and how many books are out.*

## Manage Books

**Manage Books** is the library catalogue. Filter it by category to
browse a shelf, and add to the collection with **Add Book**. Each
title tracks its copies, which is what the dashboard's available and
books-out counts are worked out from.

## Book Categories

**Book Categories** organise the catalogue — Fiction, Reference,
Science, and your own under **New Category**. Categories drive the
filter on Manage Books, so keep them the way your shelves are
arranged.

## Issue / Return Book

**Issue / Return Book** lends and collects library books. Under
**Issue a Book**, pick the book — the list shows how many copies are
available — and the student borrowing it, and the loan is recorded
against them until the book is returned through the same page.

![Issue / Return Book: pick a book, see its availability, lend it](/images/school/library/issue-book.png)
*Availability is shown per title, so you never lend a copy that is out.*
