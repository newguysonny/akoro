---
title: Promote students
description: Move a whole class to the next class at the end of session, into an optional named session.
---

**Promote Students** moves students up at the end of a session. Choose
the **From class** and the **To class**, optionally name the session
they are moving into, and **Promote** — the selected students move
together, keeping their records, fee history, and accounts intact.

![Promote Students: from class, to class, optional session](/images/school/students/promote.png)
*One action moves the whole class up.*

Promote class by class, starting from the top of the school (move the
leaving class to Alumni status first via the
[Student List](/docs/school/students/student-list-and-classes)) so each
target class is empty before its new students arrive.
