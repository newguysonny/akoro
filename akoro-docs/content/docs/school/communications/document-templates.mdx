**Document Templates** keeps all your printable templates — forms,
reports, worksheets, and certificates — in one place. The list
filters by category: Form, Certificate, Report, Result, Letter, ID
Card, or Other. From the list you can **Generate** a document from a
template, **Upload** one, or start fresh with **New Template**.

## New Template

The template editor sets the name, description, and category, then
the page itself — A4, Letter, A5, or Legal, in Portrait or Landscape.

Fields are the template's variables. Add one with **+ Field**, then
use it in the body as a double-braced key: a field named `name` is
written `{{name}}` and filled in when the document is generated.
Blank fields render as dotted lines to write on.

The body is HTML — tables, sections, and fields — with optional extra
CSS for finer control. A live preview beside the editor shows the
page exactly as it will print, updating as you type.
