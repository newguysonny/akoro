# Learning overview

Akoro's learning surface is driven by an adaptive engine that plans study,
practises topics, scores attempts and schedules review. This section describes
the learner-facing features.

> **Status: beta.** The learning engine is implemented but broad. Several
> surfaces are feature-flagged and some media states are partial. Treat these
> pages as overviews, not stable contracts.

## The core loop

1. A learner sets a goal, subject, class level and exam board.
2. The engine proposes a topic plan; the learner confirms or adjusts it.
3. The learner practises a topic and the engine scores the attempt.
4. Teach-back and confirmation gates are satisfied where required.
5. Evidence updates mastery, retention and the next review date.
6. The engine chooses the next eligible action.

## Concepts

- **Concept state** — the learner's mastery, retention and misconceptions per
  topic, stored separately from the topic definition.
- **Evidence** — observations that update mastery and review scheduling.
- **Memory** — the learner's persisted context used across sessions.
- **Decay review** — scheduling that resurfaces topics before they are
  forgotten.
