# Akoro Docs

Akoro is an education platform for learners, instructors, schools and
administrators, with an AI protégé, a Library and extraction pipeline, courses
and media, curriculum and assessments.

This documentation is the public surface of the Akoro Platform Documentation
System. Internal feature, agent and school-ERP documentation is curated before
publication.

## Start here

- [Getting started](/docs/start/getting-started) — make your first API request.
- [Authentication](/docs/start/authentication) — portals, sessions, 2FA.
- [Errors](/docs/start/errors) — error envelopes and recovery.
- [API overview](/docs/build/api-overview) — conventions and limits.
- [Uploads](/docs/build/uploads) — Library files and course video.
- [API reference](/docs/reference/api) — public and core operations.
- [Changelog](/docs/changelog) — what changed.

## Current status

The public API reference currently covers the verified auth, Library and public
catalogue surfaces. School ERP, admin and agent-internal routes are not public
API.
