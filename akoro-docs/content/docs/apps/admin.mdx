# Admin app

The Admin app is the platform-operator surface of Akoro. Platform operators use
it for cross-tenant management, moderation and AI operations.

## Scope

- **Users** — learners, instructors and school accounts.
- **Institutions** — instructors, schools and their approvals.
- **Catalogue** — courses, programmes and content moderation.
- **Analytics** — platform usage and reporting.
- **AI operations** — oversight of the platform's AI features and their usage.
- **Billing** — subscriptions and reconciliation.

## Public API

Admin operations are internal and are not part of the public API. The public
surface is an allow-listed subset; see [API reference](/docs/reference/api).
