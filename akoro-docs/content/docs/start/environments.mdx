# Environments

| Environment | Base URL | Purpose |
| --- | --- | --- |
| Production | `https://api.akoro.ng/api` | Live data |
| Sandbox | `https://sandbox.akoro.ng/api` | Integration testing with an isolated database |
| Local | `http://localhost:...` | Development |

## Demo accounts

Demo accounts are for sandbox and documentation examples only. Do not use them
for production data.

## Test data

- Use disposable records and files.
- Delete test data after the check.
- Do not place real learner or school data in examples.
