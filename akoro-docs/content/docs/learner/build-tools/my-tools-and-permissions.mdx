# My tools & permissions

Open **Settings**, switch to your agent's tab, and tap **My tools &
permissions**. Everything you have built is in one list, **MY TOOLS**.

![The MY TOOLS list: two domain tools, a computed tool that is on (used 2×, last Nov 18), and a write tool.](/images/learner/tools-list.png)
*Each row is one tool, with its own switch. Domain rows show "Domain · N actions" and open on tap.*

## Reading the list

- **Domain tools** show *Domain · N actions*. Tap the row to open the
  domain (below).
- **Computed and action tools** show what they do in one line, and — once
  used — *used N× · last \<date\>*.
- The **switch** on each row turns the whole tool on or off. A tool that
  is off is invisible to your agent: it will answer with its built-ins
  instead, and say so if you ask for the tool by name.
- A tool you kept but never turned on sits in the list switched off,
  exactly like the two domain tools in the screenshot.

## Inside a domain tool

![An opened domain: the domain's own switch, then its actions — Count, List, Group by status, Search — each with a switch and a delete button.](/images/learner/tools-domain.png)
*The domain card carries only the domain's switch; each action below has its own.*

- The **domain switch** turns the whole domain off or on at once.
- Each **action** has its own switch and a **delete** button. A deleted
  action disappears from the tool; ask your agent for it again and it
  will offer to add it back.
- The **⋮ menu** on the domain renames the domain or deletes it (with a
  confirmation).

## Deleting a tool

The **⋮ / delete** control on a tool's row removes it after a
confirmation. Deletion takes effect immediately — a deleted tool cannot
be run, even in a chat that was already open. Deleting is not the same
as switching off: off keeps the tool for later; delete removes it.
