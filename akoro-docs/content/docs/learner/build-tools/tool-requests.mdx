# Tool requests

Some asks cannot be built yet — the data is not something your agent can
read, or the action is not one it is allowed to take. When that happens,
your agent does not pretend. It explains the gap and, with your go-ahead,
**files a tool request**: a note to the Akoro team describing what you
wanted the tool to do.

## Check your requests

Ask in the chat: *"Check my requests."* Your agent lists your tool
requests (and any bug reports you have filed) with their status —
received, in review, or answered. A request is a note to the team, not a
promise: if what you asked for becomes possible, it arrives as a built-in
capability or your agent offers to build the tool again.

## Bug reports

Something broken is not a tool request. Say *"Report a bug"* (or describe
the fault and ask the agent to file it) and the agent files a bug report
instead — you can check it the same way.
