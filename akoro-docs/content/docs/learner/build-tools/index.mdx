# Build your own tools

Your agent can build small, personal tools for you: a counter for your
follow-ups, a percentage of your goals completed, a button that marks a
task done by its title. You describe what you want in the chat; the agent
builds it, shows you what it would do, and saves it only when you say
**Keep it**.

Tools are built on your own data — your tasks, goals, notes, sessions,
follow-ups, library and more — and they are yours alone: no other learner
sees or uses them.

## Core tasks

- [Ask for a tool](/docs/learner/build-tools/ask-for-a-tool) — describe
  it in the chat, review the dry run, and tap Keep on the build card.
- [When the agent offers you a copy first](/docs/learner/build-tools/own-copy-offer)
  — if a built-in tool already does the job, the agent says so and asks
  before building yours.
- [My tools & permissions](/docs/learner/build-tools/my-tools-and-permissions)
  — every tool you own, in Settings: turn tools and single actions on or
  off, rename or delete them.
- [Tool requests](/docs/learner/build-tools/tool-requests) — when a tool
  needs data your agent cannot reach yet, the request is filed and
  tracked.
- [Limits](/docs/learner/build-tools/limits) — 20 tools, 8 actions per
  domain tool, and what a tool can and cannot do.

## Where tools live

Built tools appear in **Settings → (your agent) → My tools &
permissions**, and your agent uses them in the chat whenever they fit
what you ask.

![The agent's settings tab, where My tools & permissions lives.](/images/learner/settings-agent.png)
*Settings has two tabs: Account, and your agent's — My tools & permissions is on the agent tab.*
