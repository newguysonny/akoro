# When the agent offers you a copy first

Sometimes what you ask for is already covered by one of your agent's
built-in tools — a built-in can already count your follow-ups, list your
tasks, and so on. When that is the case, the agent will not quietly build
a duplicate. It tells you:

- the built-in already does this, and what it returns;
- what **your own copy** would add — your name for it, your grouping,
  your extra step — if anything;
- and asks: **do you want your own copy anyway?**

Say yes and the build goes ahead (you will still get the
[Keep card](/docs/learner/build-tools/ask-for-a-tool)). Say no and the
agent simply uses the built-in — your ask is answered either way.

## When the offer does not appear

- Extending or rebuilding a tool you already own — that is yours to
  change freely.
- A computed tool (a calculation) — those are never duplicates of a
  domain tool.
- A tool the agent is resuming from an earlier conversation.
