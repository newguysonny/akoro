# Ask for a tool

Ask in the [agent chat](/docs/learner/agent-chat/ask-your-agent), in
plain words: *"Build me a tool that tells me what percentage of my goals
I've completed."*

## What happens

1. **The agent checks whether a tool is needed at all.** A one-off
   question just gets an answer — no tool is built for something you
   asked once.
2. **It builds a draft and tries it.** The draft runs once against your
   real data, privately, so you can see exactly what the tool returns.
3. **It tells you the result — and the limits.** You hear what the tool
   found on the trial run and anything it cannot do.
4. **A build card asks you to keep it.** The tool is saved **off** as a
   draft until you decide:
   - **Keep it** — the tool turns on and runs once, for real. From then
     on your agent can use it whenever it fits.
   - **Not now** — the draft is archived. Nothing stays on.

## Two kinds of tools

- **Domain tools** wrap one area of your data — your follow-ups, your
  tasks, your goals — as a fixed set of actions: count, list, group,
  search, and the like.
- **Computed tools** work something out: a percentage, a total, a
  comparison across your data. A computed tool that only reads is
  answered on the spot; you save it when you want it again. If a computed
  tool would *change* rows, it shows you the exact rows on a card first
  and changes nothing until you confirm.

## If you keep asking the same thing

Ask for the same calculation a few times over two weeks and your agent
may suggest saving it as a tool — the suggestion is all that happens;
the tool still only exists if you keep it.
