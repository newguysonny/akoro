# Attach a file

In the chat composer, tap the **+** button (**Add a photo or file**) and
pick a photo or a document — class notes, a past question paper, a
textbook chapter. The file appears as a tile in the composer; add a line
saying what you want (*"Explain page 2"*, *"Quiz me on this"*), or send
it on its own.

## What happens when you send it

1. **Your agent reads the file.** Reading starts as soon as the file is
   attached. A short document is ready in seconds; a long scanned
   document takes longer, and the chat shows the reading step while it
   runs.
2. **Your agent narrates what it found** — the subject, the topics, and
   anything it could not read — in the chat, as its own messages.
3. **Your agent files it in your library**, in a folder it picks from the
   content (and says which), so the document is there next time — see
   the Library guides.
4. **Then it answers.** Ask questions about the document in the same
   chat; the agent answers from what it read.

## Good to know

- Photos of handwritten or printed pages work — the agent reads the page
  as an image when there is no text layer.
- A file you attach in a chat is the same file that lands in your
  library; there is no separate upload to manage.
- If a file cannot be read at all, the agent tells you in the chat rather
  than guessing from the file name.
