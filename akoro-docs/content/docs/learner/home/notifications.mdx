# Notifications

Tap the **bell** in the header to open Notifications. The badge on the
bell shows how many are unread; the page header repeats the count.

![Notifications: 141 unread, All and Unread filters, Mark all read, and per-item Mark read and Delete.](/images/learner/notifications.png)
*Live classes starting and agent notices are the commonest kinds.*

## What arrives here

- **Live class started** — a class or daily session is live now; the
  notification tells you to tap Join Live to enter.
- **Your agent noticed something** — the same proposals that appear as
  the [Needs you card](/docs/learner/home/the-needs-you-card) on Home.
- Battles, results and other app events, as they happen.

## Managing the list

- **All / Unread (N)** — filter the list.
- **Mark read** — clears one item's unread state.
- **Delete** — removes one item.
- **Mark all read** — clears the whole unread count at once.

Tapping a notification itself takes you to the thing it is about — the
live class, the chat, the result.
