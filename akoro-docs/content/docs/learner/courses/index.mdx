# Courses and programmes

Akoro's study content is a hierarchy:

**Programme → Sections → Courses → Modules → Lessons**

A **programme** (your degree or exam track — PharmD, a WAEC track, a
school programme) groups **sections**; each section holds **courses**;
each course is a set of **modules**; each module is **lessons** —
videos, readings, quizzes. Every level has its own page.

## Where courses live

Find them in [Discover](/docs/learner/discover); once enrolled, they
sit in your [Library](/docs/learner/library) with a progress bar, and
their sessions appear in [My Sessions](/docs/learner/study/teaching-sessions).
