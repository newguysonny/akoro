# Help & About

**Settings → Account → Help & About.**

![Help & About: the support rows, then App Version, Terms of Service, Privacy Policy, and Open Source Licences.](/images/learner/settings-help.png)

## Help & Support

- **Contact Support** — reach the Akoro team directly.
- **Help Centre** — the help library in the app.
- **Report a Bug** — something broken? File it here. You can also
  tell your agent in chat — *"report a bug"* — and it files through
  the same support channel; either way, check on it later from the
  chat (*"what happened with my requests?"*).
- **Rate the App** — the store rating, if Akoro has earned it.

## About & Version

- **App Version** — the build you are running (v1.0.0 here). Quote it
  in any bug report; it is the first thing support needs.
- **Terms of Service** and **Privacy Policy** — the legal pages, in
  the app.
- **Open Source Licences** — the open-source software Akoro is built
  with, credited.
