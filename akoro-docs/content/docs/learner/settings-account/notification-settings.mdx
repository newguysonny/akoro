# Notification settings

**Settings → Account → Notifications.** This page decides *how*
Akoro reaches you; the notifications themselves live in
[Home → Notifications](/docs/learner/home/notifications).

![Notification settings: the channel toggles, the event toggles, and the Schedule Alarm sound.](/images/learner/settings-notifications.png)

## Channels

- **Email Notifications** — class updates and reminders.
- **SMS Notifications** — text message alerts (needs a phone number
  on your [Profile](/docs/learner/settings-account/profile)).
- **Push Notifications** — in-app and device alerts.
- **WhatsApp** — WhatsApp messages.

A channel off is off everywhere: events only travel on channels you
have enabled.

## Events

- **Session Reminders** — reminded before class starts.
- **Session Started** — when your live class begins.
- **Session Cancelled** — if a class is cancelled.
- **Announcements** — new posts from instructors.
- **Q&A Replies** — when someone replies to you.

## Schedule Alarm

**Alarm sound** — *Rings like an alarm when a live class starts.*
Pick the sound (Classic Chime here) if a gentle notification is too
easy to sleep through: the alarm is the notification that behaves
like it matters.
