# Reading a document

![The Reader on a pasted-text record: header, Original Content tab, page 1 of 2, zoom at 100%, and the paginated document.](/images/learner/reader-text.png)
*The Reader lays the document out as pages, whatever it started as — PDF, link or pasted text.*

## The anatomy

- **Header** — the document's title and where it came from
  (*Library record · paste*, *Library record · upload*), and a back
  arrow that returns you to where you opened it from.
- **The tab strip** — **Original Content** is the document itself.
  Other pills appear as you generate tools from it.
- **Page controls** — previous / next and the position, *1 / 27*.
- **Zoom** — step the scale down or up; 100% is the default fit.

## Reading a fresh upload

Open a document whose text is still being extracted and the Reader
shows an **Extracting the text…** card with the page it has reached,
over the pages it has already rendered. Reading can start at once;
[Ask](/docs/learner/reader/ask-in-the-reader) and the study tools
unlock as extraction completes.

![A 27-page PDF mid-extraction: the progress card over page 1.](/images/learner/reader-extracting.png)
*Long documents extract page by page — the card counts so you know it is moving.*
