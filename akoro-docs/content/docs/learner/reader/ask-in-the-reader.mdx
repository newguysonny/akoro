# Ask in the Reader

Beside the document sits **Ask**: a chat pane scoped to this document
alone. Ask anything about what you are reading — *"What does the Golgi
body do?"* — and the answer is built from the document's own text, not
from the open web or the model's general knowledge.

## Suggestions

Ask offers **suggestion chips**: questions worth asking about this
document, drawn from its examinable concepts — the things a teacher
could set a question on. Tap one instead of typing. If a chip ever
looks like filler (a stray heading or a table label), it is a bug, not
a feature — the chips are meant to be real questions.

## Answers carry their sources

Every Ask answer ends with its [citation](/docs/learner/reader/citations):
the place in the document the answer came from. Tap it to jump to that
page and read the passage yourself.

## Ask vs the agent chat

Ask is one document deep. The [agent chat](/docs/learner/agent-chat)
is everything wide — it can draw on this document plus your whole
Library, your courses and your history. Use Ask while reading; use the
agent when the question is bigger than the page.
