# The assessment room

Some live sessions carry an assessment. Open the session's sheet from
[My Sessions](/docs/learner/study/teaching-sessions) and tap **Take live
assessment** to enter the assessment room.

## What to expect

- The assessment belongs to that session and its subject — it is set by
  the instructor, not generated on the spot.
- Answer inside the room and submit there; there is no separate upload.
- Your result joins your [gradebook](/docs/learner/study/your-gradebook)
  with the session's other work, and the topics it covered feed your
  confidence record like any other assessed work.

## If the button is not there

Not every session has a live assessment — the button appears only on
sessions that carry one. For self-testing at any time, use
[practice](/docs/learner/study/practice) with your agent instead.
