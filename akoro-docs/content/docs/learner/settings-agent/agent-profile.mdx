# Agent Profile

**Settings → (agent tab) → Agent Profile.** Four rows make your agent
*yours*:

![Agent Profile: Agent Name, Personality, Agent Colour, Card Background.](/images/learner/settings-agent-profile.png)

- **Agent Name** — Nova here. Rename it and the new name follows the
  agent everywhere: the Settings tab, the chat header, the network.
- **Personality** — how it talks and teaches (*Not set* until you
  choose). The personality colours tone, not knowledge: a stricter
  agent and a gentler one teach the same facts differently.
- **Agent Colour** — its colour (the orange dot). Subject chips in
  its study profile and its card accents wear it.
- **Card Background** — the backdrop on the agent's card.

## Why bother

The agent is the face of Akoro — you talk to it daily. Naming it and
setting its personality is the difference between a tool and *your
tutor*. Onboarding picked a name with you; this page is where it can
change as you settle in.
