# Agent Memory

**Settings → (agent tab) → Memory.** Your agent's memory of you,
written out where you can read it — no hidden profile.

![The Memory list: entries in plain sentences, each tagged with its kind, subject, and date.](/images/learner/settings-agent-memory.png)

## What an entry looks like

Each memory is a plain sentence about you, with a tag line:

- **What you studied** — *"Essay writing in English Language is still
  shaky for Adaeze; she has not yet re-taught the structure and
  paragraph rules."*
- **About you** — habits and patterns: *"Adaeze tends to put off
  practising weak topics until Friday…"*
- **To come back to** — threads left open: a quiz waiting on a
  re-teach, a routine offered but not confirmed.
- **Your goal** — the [Learning Goal](/docs/learner/settings-agent/learning-goal),
  remembered.
- **How you like to learn** — *"Adaeze prefers short worked examples
  and a practice question after each step."*

Each entry carries its subject and the date it was noted.

## Where memories come from

The **Learn from my conversations** toggle in
[Autonomy](/docs/learner/settings-agent/autonomy): after a chat goes
quiet, the agent notes what would help it help you — *never health,
feelings, money or contact details*, by the toggle's own rule.

## Forgetting

- **Per entry** — each row has its own control: remove the memory
  that is wrong, stale, or simply not wanted. Your agent relearns
  from future chats; a deleted memory is not a ban on the topic.
- **Forget everything** — the button at the bottom wipes the whole
  list. Your agent starts fresh: same subjects and level (those are
  settings, not memories), but no remembered habits, preferences, or
  open threads.
