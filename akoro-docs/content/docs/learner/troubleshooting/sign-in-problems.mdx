# Sign-in problems

## The code never arrives

The 6-digit email code (sign-up, or a guarded sign-in) fails in
predictable places:

1. **Spam / promotions.** Look there first — code emails land there
   constantly.
2. **The address.** A typo at sign-up sends codes to a stranger's
   inbox (or nobody's). On the code screen, **← Back** and check the
   address letter by letter.
3. **Resend code.** Sends a fresh code and retires the old one — do
   not keep typing the first code after resending.
4. **Wait a minute.** Email is not instant; a code requested twice in
   ten seconds often arrives as two emails, oldest first. Use the
   newest.

## The password keeps failing

- **Caps and keyboard.** Passwords are case-sensitive; a new phone
  keyboard is the usual culprit.
- **Reset it.** [Forgot password](/docs/learner/getting-started/forgot-password)
  — the reset link goes to the account's email; follow it and set a
  new one (min 8 chars).
- **Changed it recently?** Other devices keep the old session until
  it expires; sign out there and back in with the new password.

## Google sign-in will not let me in

- The Google account's email must match your Akoro account — a
  different Google address is a different identity, and Akoro will
  offer to create a *new* account instead. Back out and pick the
  right Google account.
- If your Profile email reads *Linked via Google*, Google is the
  expected way in for that account (see
  [Privacy & Security](/docs/learner/settings-account/privacy-and-security)
  → Linked Accounts).

## Two-factor asks for a code I do not have

Two-Factor Auth (Privacy & Security) guards sign-in with a second
proof. If you have lost access to that proof entirely, this is a
support case, not a settings fix:
[Contact Support](/docs/learner/settings-account/help-and-about),
with your **Account ID** (Privacy & Security, tap to copy) ready.
