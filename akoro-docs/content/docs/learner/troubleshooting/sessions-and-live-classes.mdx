# Sessions and live classes

## I cannot join the live class

1. **Is it live yet?** The session sheet shows the state; **Join
   Live** works when the class starts, not before. Upcoming classes
   sit in [My Sessions](/docs/learner/study/teaching-sessions) with
   their time.
2. **Are you enrolled?** Live classes belong to courses — an
   unenrolled course's class can be seen in Discover but not joined.
   [Enrol](/docs/learner/courses/enrol-and-the-cart) first.
3. **Time zone again.** A class at "4 pm" reads your Profile time
   zone. Wrong zone, wrong hour.

## I minimised a session and lost it

You did not lose it. Minimising (**−**, *Minimize & continue later*)
parks the session exactly where you left it — it waits in **My
Sessions** and in the agent's awareness; reopen it from either. See
[Teaching sessions](/docs/learner/study/teaching-sessions).

## The reminder never rang

- **Notification settings** — Session Reminders and Session Started
  must be on, on a channel that is on (email/SMS/push/WhatsApp).
- **The alarm** — for live classes, the **Schedule Alarm** sound is
  separate from ordinary notifications; check it is set in
  [Notification settings](/docs/learner/settings-account/notification-settings).
- **Device permissions** — push needs the device's permission for
  Akoro, granted outside the app. If push shows off and greyed, the
  device said no first.

## A session ended but shows as still running

Counts and lists settle a few moments after a session closes. Pull
to refresh the list; if it persists past a day, it is a bug —
[Report a Bug](/docs/learner/settings-account/help-and-about) with
the session's subject and time.
