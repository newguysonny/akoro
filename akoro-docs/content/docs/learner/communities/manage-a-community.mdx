# Manage a community

Owners open **Community settings** from the community page's header:

![Community settings: the icon grid, name and description fields, Save changes — and the Danger zone with Delete this community.](/images/learner/community-settings.png)

## The editable identity

- **Icon** — the same grid as creation.
- **Community name**
- **Description**

**Save changes** applies them everywhere the community appears —
cards, lists, and members' pages alike.

## Analytics

The header's **Analytics** button is the owner's other tool: how the
community's activities are going — what was posted, what was
submitted, who is keeping up. Check it before posting more work into
silence.

## Danger zone: Delete this community

Deleting a community is permanent: the community, its feed, and its
shared shelves go for everyone, all at once. Members keep their own
libraries and work — only the shared room closes. There is no undo,
so the button sits alone in the Danger zone, and it is owner-only.
