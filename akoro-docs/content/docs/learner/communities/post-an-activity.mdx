# Post an activity

On the community page, tap **New activity**:

![The New activity sheet: type chips, activity name, subject, class, a due date and time, optional instructions, and Post activity.](/images/learner/community-new-activity.png)

1. **Type** — Assignment, Project, Multi stage, Self study, or Live
   course. The type decides how the activity behaves in members'
   lists and gradebooks.
2. **Activity name** — what members see.
3. **Subject** and **Class** (e.g. CSC 201) — how it files and
   filters.
4. **Due date and time** — the deadline members work to.
5. **Instructions (optional)** — what to do, in your words.
6. **Post activity.**

## What members see

The activity joins the community feed under its type filter, and
surfaces in each member's own activity lists — the same lists covered
in [Self-study activities](/docs/learner/study/self-study-activities).
Members open it, do the work, and submit; submissions feed the
owner's [gradebook](/docs/learner/study/your-gradebook) view and the
community's analytics.
