# Verify your email

Creating an account ends on this screen:

![Check your email: enter the 6-digit code sent to your address, then Verify code. Resend code and Back sit below.](/images/learner/verify-email.png)

## The steps

1. Open the email Akoro just sent your address.
2. Type the **6-digit code** into the boxes.
3. Tap **Verify code**.

That is the whole job: the code proves the address is yours, and
your account is finished.

## When the code does not come

- **Resend code** — sends a fresh one. Check spam first; resending
  starts a new code and retires the old one.
- **← Back** — returns to sign-up if the address itself was wrong
  (a typo'd email is the most common cause of a code that never
  arrives — fix the address, not the code).

## Codes also guard sign-in

The same code step can appear when you sign in on a new device or
after a security change: an email code is Akoro's way of asking
*still you?* before letting a session start.
