# Forgot password

On the sign-in screen, tap **Forgot password?**

![Forgot password: enter your email address and Send reset link.](/images/learner/forgot-password.png)

## The flow

1. Enter the **Email address** your account uses.
2. Tap **Send reset link**.
3. Open the email and follow the link.
4. Set a new password (at least 8 characters, like sign-up).
5. Sign in with it.

**← Back to sign in** is at the bottom if you remember the password
mid-flow.

## If the email does not arrive

- Give it a minute, then check **spam/promotions** — reset emails
  land there more than anywhere.
- Make sure the address is exactly the one on the account; a reset
  link can only go to the account's own email.
- Still nothing? [Contact Support](/docs/learner/settings-account/help-and-about)
  from any signed-in device, or ask a teacher to help you reach the
  team.

## After you are back in

Consider turning on **Two-Factor Auth** under
[Privacy & Security](/docs/learner/settings-account/privacy-and-security):
a forgotten password is an annoyance; a guessed one is a breach.
