# Install Akoro

Akoro installs from the web: no store, no waiting for a download to
finish. An installed Akoro gets its own icon on your home screen and
opens full-screen, like any other app.

## From the landing page

The **Install** button on Akoro's home page (www.akoro.ng) starts it:

1. Tap **Install**.
2. If you are signed out, you will be asked to **sign in first** —
   your install intent is remembered across the sign-in, and the
   install prompt picks up right where you left off.
3. Confirm the browser's install prompt.

## From inside the app

If you already use Akoro in the browser, the app offers the same
install itself — accept the prompt (or the install row in the app's
menu/drawer) and the icon lands on your home screen.

## Good to know

- **Same account, same everything.** Installing changes the wrapper,
  not the contents: your agent, library, tools and progress are your
  account's, on any device.
- **The icon follows your theme.** The installed icon and the browser
  tab favicon use the artwork for your device's light/dark mode.
- **Uninstalling is the device's job** — long-press the icon and
  remove it like any app. Your account is untouched; sign in on the
  web any time.
