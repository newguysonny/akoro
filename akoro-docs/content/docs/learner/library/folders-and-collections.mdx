# Folders and collections

Folders are how a big Library stays usable: one per subject, per exam,
per term — your call.

## Create a folder

Tap **+** in the Library and choose **Create a folder**: give it a
**name**, a **cover**, a **description**, and a **visibility**. The
folder appears under the **Folders** chip.

![The Folders view before the first folder exists.](/images/learner/library-folders.png)
*A new account starts with no folders — the Folders chip is where they collect.*

## File a record into a folder

Open the record's [⋯ sheet](/docs/learner/library/record-actions) and
choose **Add to folder**, then the folder. A record lives in the
Library list and in its folder at the same time — filing is organising,
not moving house. Your agent also files for you: when it saves an
upload from the chat, it picks the folder that fits and tells you which
one.

## Collections

The **Collections** chip groups what you have *saved* — courses,
guides, blogs — as opposed to folders, which organise your own
*records*. Same shelf, two kinds of order.
