# Upload a record

Tap the **+** button at the top of the Library and choose **Upload a
record**.

![Add to library: Upload a record — files, links or pasted text — or Create a folder.](/images/learner/library-add-sheet.png)
*The + sheet: one door for records, one for folders.*

## The three ways in

- **File** — a document from your device (PDFs and other document
  files). The record appears in your Library with its size and date.
- **Link** — a web address; Akoro fetches and keeps the content.
- **Pasted text** — copy text in directly; it becomes a text record,
  like the *Cell structure: organelle functions* note in the Library
  screenshots.

## While Akoro reads it

A new record is **extracted** — its text is read so your agent can
teach from it, answer questions about it, and generate study tools.
You will see the state on the record (*New*, then a percentage) and,
if you open it early, an *Extracting the text…* card with the page it
has reached. Text you paste is ready almost at once; a long scanned
PDF takes longer. The record is usable as soon as extraction finishes.

## The other door: the chat

You can also [attach a file in the agent chat](/docs/learner/agent-chat/attach-a-file) —
your agent reads it, files it into your Library, and answers from it in
the same conversation. Both doors land in the same Library.
