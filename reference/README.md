# Historical references

## `agent-from-scratch/`

This is a read-only source snapshot of the original standalone Python agent
foundation, preserved from commit `591db68` (`feat(agent): add structured Python
agent foundation`) before it became the deployable `akoro-python-agent` service.

It is intentionally kept outside the active project and deployment path. Do not
change it when developing or deploying `../akoro-python-agent`; use it only to
compare the original generic agent structure and behavior.
