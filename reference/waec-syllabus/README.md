# WAEC syllabuses (WASSCE / SSCE) — unofficial copies

The WAEC examination syllabus for each SSCE/WASSCE subject, downloaded from the third-party site
**https://waecsyllabus.com/**. Each PDF opens with the council's own preamble ("This is an examination syllabus drawn up
from the curricula of the member countries of the West African Examinations Council…").

> **These are unofficial copies.** WAEC's own sites (waecnigeria.org, waecdirect.org) do not publish the syllabus
> files where we could reach them, so these come from a mirror. Some are old: the Biology PDF's metadata is dated
> 2015 and credits another site as its compiler, and the Commerce file's server date is 2022. Before building
> anything learners rely on, check a syllabus against the current WAEC document (the "Syllabus" section of the
> candidate's registration pages, or ask the school's WAEC officer).

- **Downloaded:** 2026-10-25, unmodified, 64 subjects — about 10 MB.
- **Where the files were:** the site's own links (`/files/ssce/…` and `/download/ssce/…`); the "Original name" column
  is the file name it uses.
