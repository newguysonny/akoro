## Rules

- Use `_templates/feature.md`.
- Declare status: implemented, beta, planned, deprecated or disabled.
- Link capabilities, API operations and data models.
- Document permissions and ownership checks.
- Document failure and edge cases.
- Do not describe a planned feature as available.

## Not yet documented

- Learner AI/teaching/study/exam/practice/memory.
- Instructor course building and grading.
- School ERP.
- Admin operations.
- Agent runtime and proposals.
- Payments, wallets and vouchers beyond the public contract.

These are Tier 2/3 and require module-level grouping, not one page per route.
