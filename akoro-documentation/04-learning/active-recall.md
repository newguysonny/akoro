# Active recall

## What it means in Akoro

Active recall is implemented as **retrieval practice**: the learner is asked
to produce an answer from memory before any re-explanation, and the result
is recorded as evidence. It is not a separate "active recall mode"; it is
the checking mechanism the whole engine is built around — Study Prep topics
are only marked `understood` after a scored check, and Decay Review exists
to test whether previously learned material can still be recalled.

## How the engine implements it

- **Agent Checks.** Study Prep runs a diagnostic check per topic (and a
  retest after intervention). Scoring is deterministic answer-key scoring
  in the Education Engine — the LLM never scores an attempt.
- **Retrieval practice strategy.** The Strategy Library entry
  `retrieval_practice` (v2) targets the `decay` and `retrieval_failure`
  struggle types, runs in the decay_review and practice workflows, and is
  executed by the harness as `recall_rounds`. Its success criterion: "the
  learner recalls it with no hint or a cue." It is flagged `humanAnswers` —
  the learner answers; the agent does not answer for them.
- **Decay Review recall rounds.** When a retention check verdict is
  `decayed`, the review moves to retrieval practice first: up to 3 recall
  rounds (`DECAY_POLICY.RETRIEVAL_ROUNDS`). Each round has a hint ladder —
  `none → cue → partial` — and a hint lowers what a right answer counts
  for: a correct answer with a hint counts as `partial`, and a partial
  answer with a hint counts as `incorrect` (`recallOutcome` in
  `decay-review/workflow.js`).
- **Mastery effect.** The mastery write-back weights fresh attempt evidence
  more heavily as attempts accumulate, which the code comments describe as
  the retrieval-practice effect; see [Mastery framework](mastery-framework.md).

## Deterministic vs AI-decided

Deterministic: check scoring, round and hint caps, outcome downgrading for
hinted answers, and all state transitions. AI-decided: in Decay Review the
recall *questions* are generated by a model call (question, cue, partial
hint and answer key; the key never leaves the server), and free-text recall
answers are judged by a separate assessor-role model call returning
correct / partial / incorrect. MCQ checks in Study Prep and Practice are
scored without any model involvement.

## Agent authority

The agent may offer retrieval practice where the Strategy Library permits
it and may conduct recall rounds. Only the engine decides whether recall
succeeded, how many rounds remain, and what evidence a round writes. The
agent must not reveal the answer key, skip the hint ladder ordering, or
treat a hinted correct answer as unhinted recall.

## Failure and edge behaviour

- If no recall question can be generated for a decayed topic, the review
  goes straight to the retest instead of stalling.
- After retrieval practice, a retest decides the outcome; a failed retest
  escalates to re-teaching (teach-back), not to more recall rounds.
- A concept a review never reached gets no outcome and keeps decaying.
