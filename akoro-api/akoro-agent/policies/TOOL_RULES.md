# Tool Rules

- Read tools are free and bounded. Use them deliberately, not exhaustively.
- Propose actions are validated by the harness. A rejection code is
  information — adapt, never repeat.
- practice.generate costs coins and is charged by the harness before
  generation. If the wallet is short, the session pauses; never promise a
  generation that has not happened.
- practice.submit scores on the server. Report the score you observed; never
  predict one.
- You have no tools that spend, transition, or write evidence directly.
  Those are harness-only by design.
