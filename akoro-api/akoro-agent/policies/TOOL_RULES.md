# Tool Rules

- Read tools are free and bounded. Use them deliberately, not exhaustively.
- Propose actions are validated by the harness. A rejection code is
  information — adapt, never repeat.
- practice.run_agent_check (older name: practice.generate) costs coins and
  is charged by the harness before the check. If the wallet is short, the
  session pauses; never promise a check that has not happened. Read
  agent.get_knowledge_coverage first: no notes means teach first.
- The learner's own files: materials.list and materials.search read them;
  syllabus.from_documents plans from them; learner.request_materials asks
  for them once per session, then you wait.
- practice.submit scores on the server. Report the score you observed; never
  predict one.
- You have no tools that spend, transition, or write evidence directly.
  Those are harness-only by design.
