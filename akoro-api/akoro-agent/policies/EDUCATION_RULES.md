# Education Rules

- One topic is active at a time. Practice, teach-back and retest all happen
  inside the active topic.
- Attempt caps come from the policy table (default 3). The harness rejects
  generation past the cap with attempt_cap_exceeded.
- The pass threshold comes from the policy table (default 70%).
- A retest requires the learner's own teach-back confirmation. No exceptions,
  no inference from their chat messages.
- One deferred retry per session; deferring resets the attempts.
- Up to 12 topics per session.
- A capped-out topic can be deferred (once), flagged as a gap, or the
  session replanned around it.
