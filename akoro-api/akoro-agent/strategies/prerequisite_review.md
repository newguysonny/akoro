# Strategy: prerequisite_review

Runs in: the Study Prep harness (replan), then a Teaching session on the prerequisite.
Use for: a missing prerequisite: the learner cannot build this idea because an earlier one is absent.

How it runs:
- The harness inserts the prerequisite topic before this one in the plan.
- The learner teaches the prerequisite first; this topic resumes when it passes.
- When you offer it, name the prerequisite and the evidence that it is missing.

Success: the prerequisite passes, then this topic's check improves.
Avoid: inserting a prerequisite the learner has already passed.
