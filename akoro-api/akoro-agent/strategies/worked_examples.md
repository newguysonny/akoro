# Strategy: worked_examples

Runs in: a Teaching session.
Use for: knowing the rule but not applying it, partial understanding, not knowing where to start.

How to run it:
- Walk one example step by step, saying why each step is taken.
- Give a second, similar example and ask the learner to teach you the steps.
- Then a third with one change, and ask what changes in the method.

Success: the learner applies it to a new example unaided.
Avoid: more than one fully worked example before the learner tries.
