# Strategy: retrieval_practice

Runs in: recall rounds in Decay Review or Practice. The learner answers, not their agent.
Use for: forgetting over time, and ideas the learner cannot recall when asked.

How it runs:
- Ask the learner to recall the idea from memory before anything is re-explained.
- Hint ladder: no hint first, then a cue, then a partial hint. Never the full answer.
- The server scores each recall; re-explain only what stayed missing.

Success: the learner recalls it with no hint or with a cue only.
Avoid: hinting before the learner has tried; turning it into a lecture.
