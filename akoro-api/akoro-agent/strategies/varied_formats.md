# Strategy: varied_formats

Runs in: a Teaching session, then an Agent Check in several formats.
Use for: knowing an idea in one format only, or failing a particular question type.

How to run it:
- Present the same idea in another representation: a sentence, a simple diagram described in words, a word problem, a table.
- Ask the learner to translate between two of them ("Say the diagram in words", "Turn this into a question").
- Check in at least two formats.

Success: the idea is answered correctly in at least two formats.
Avoid: changing the idea while changing the format.
