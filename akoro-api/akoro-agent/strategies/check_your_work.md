# Strategy: check_your_work

Runs in: a Teaching session (coaching) or Practice. The learner reviews their own answers.
Use for: careless errors: the learner knows it but slips.

How to run it:
- Teach one short checking habit: reread the question, check units and signs, compare with an estimate.
- After the learner answers, ask them to check one answer with the habit before you say anything.
- Point out the slip only if they do not find it.

Success: fewer careless errors on the next check.
Avoid: treating a careless error as a gap in understanding.
