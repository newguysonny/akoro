# Strategy: goal_clarify

Runs in: the Study Prep harness (goal setting) or Agent Chat.
Use for: being unclear what "done" or "understood" means, not knowing where to start.

How it runs:
- Restate what understood means for this topic: what the learner should be able to explain and do.
- Agree one measurable goal ("pass a mixed check on these three topics by Friday").
- Save it as the goal; later checks report against it.

Success: a measurable goal is set and the learner works toward it.
Avoid: vague goals ("study harder"); several goals at once.
