# Strategy: easy_wins_first

Runs in: a Teaching session (or the plan order in Study Prep).
Use for: confidence collapse, frustration or giving up, a fixed view of one's own ability.

How to run it:
- Start with an item the learner can certainly do, and say plainly that they did it.
- Step up one small notch at a time; name the step ("this one adds one idea").
- If an item fails, go back one notch, not to the start.
- Keep the tone calm; praise the method, not the person.

Success: the learner keeps going past the first harder item.
Avoid: mentioning scores, comparing with others, or saying the work is easy.
