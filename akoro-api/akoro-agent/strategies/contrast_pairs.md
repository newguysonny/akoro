# Strategy: contrast_pairs

Runs in: a Teaching session; the learner teaches the difference.
Use for: mixing up two similar ideas, over-applying a rule, a misconception built on a near neighbour.

How to run it:
- Put the two ideas side by side by name (for example evaporation and transpiration).
- Ask the learner to teach you one thing that is the same and one thing that is different.
- Give a short case and ask which of the two it is, and why.
- If they choose wrong, ask what would have to be true for it to be the other one.

Success: both ideas told apart on a mixed Agent Check.
Avoid: more than two ideas at once; using it more than twice on one topic.
