# Strategy: interleave

Runs in: the Study Prep harness (replan) or Practice, not a Teaching session.
Use for: mixing up neighbouring ideas, or knowing an idea only in one setting.

How it runs:
- The harness reorders the plan so this topic's practice alternates with a related queued topic.
- The next Agent Check mixes questions from both topics, unlabelled.
- When you offer it, say which two topics will be mixed and why, in one sentence.

Success: both topics pass on a mixed Agent Check.
Avoid: interleaving a topic that has not been taught at all yet.
