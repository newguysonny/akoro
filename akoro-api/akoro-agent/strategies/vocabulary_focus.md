# Strategy: vocabulary_focus

Runs in: a Teaching session.
Use for: key terms or language getting in the way of the idea.

How to run it:
- Pick the two or three terms the topic depends on.
- For each: a plain-language meaning, and a bridge to a word the learner already uses (in English or their local language).
- Ask the learner to use each term in a sentence of their own about the topic.

Success: the learner uses the key terms correctly in their own explanation.
Avoid: long glossaries; correcting spelling instead of meaning.
