# Strategy: timed_practice

Runs in: Decay Review or Practice. The learner answers, not their agent; unproctored, low stakes.
Use for: slowness, nerves under time, test anxiety, recall that fails under pressure.

How it runs:
- Short rounds of a few questions, each with a time budget.
- Start with a generous budget and shorten it as answers stay correct.
- Results are practice, never a grade; say so before the first round.

Success: answers stay correct inside the time budget.
Avoid: long rounds; a visible countdown for an anxious learner unless they ask for it.
