# Strategy: chunk_plan

Runs in: the Study Prep harness (replan).
Use for: overload, running out of time mid-topic, deadline pressure.

How it runs:
- The harness splits the topic (or the plan) into smaller parts, each with its own short check.
- Shorter sessions; one part at a time.
- When you offer it, say how many parts and roughly how long each takes.

Success: the smaller parts are finished on time.
Avoid: splitting below the size of one must-know idea.
