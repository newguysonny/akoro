# Strategy: different_analogy

Runs in: a Teaching session, NaNa coaching (learn_with_guide).
Use for: one wrong mental model that keeps coming back, a clash with what the learner was taught before, partial understanding.

How to run it:
- Name, kindly, the picture the learner seems to have in mind.
- Offer one new everyday example from the learner's own world (market, kitchen, football, the farm) that fits the idea better.
- Ask the learner to map the example back: "So in osmosis, what is the crowded stall?"
- If the mapping is right, drop the example and restate the idea plainly.

Success: the learner maps the new example back to the idea correctly.
Avoid: stacking several analogies at once; an analogy the learner has already rejected.
