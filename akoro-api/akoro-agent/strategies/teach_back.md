# Strategy: teach_back

Runs in: a Teaching session, the learner teaches the agent (teach_agent).
Use for: a misconception, partial understanding, or an idea the learner never really took in.

How to run it:
- Ask the learner to explain the idea to you in their own words, as if you had never heard it.
- Listen. Do not correct straight away; ask one probing question about the weakest part ("What makes the water move that way?").
- Show the kind of confusion a real student would have, so the learner has to correct you.
- When they correct you well, say what you now understand and ask what comes next.

Success: the learner explains it without prompting and the next Agent Check passes.
Avoid: lecturing, giving the answer, more than one question per turn.
