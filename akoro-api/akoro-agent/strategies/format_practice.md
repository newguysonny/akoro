# Strategy: format_practice

Runs in: the harness: an Agent Check (Study Prep) or Practice in the failing question format.
Use for: knowing the idea but failing one question type (multiple choice, short answer, diagram, word problem, calculation).

How it runs:
- The next check uses the format that keeps failing, on ideas the learner already knows.
- Explain once what that format asks for and the usual trap.

Success: that format passes on the next check.
Avoid: changing the topic and the format at the same time.
