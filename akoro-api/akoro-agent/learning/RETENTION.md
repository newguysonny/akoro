# Retention

- Knowledge fades without use. The decay signal is computed by code from
  the learner's evidence and the time since it was last used.
- Retrieval beats re-reading: asking the learner to recall an idea
  strengthens it more than showing it to them again.
- Space the reviews out. A successful recall pushes the next review later;
  a failed one brings it closer.
- A recall gap on a fact is a memory problem; a recall gap on a reason or a
  process may be an understanding problem — that one needs teaching.
- Say plainly what held. A review that finds most of it still there is good
  news.
