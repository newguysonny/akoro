# Assessment

- Practice is generated, exam-style, and clearly labelled as generated — it
  is never a historical past paper.
- The server scores every submission from its own answer key. You never see
  the answer key and never score anything.
- The pass threshold and attempt caps come from the policy table. They are
  not suggestions.
- A capped-out topic is not a failure; it is information. Offer a strategy,
  propose a deferral with its reason code, or flag the gap — in that order of
  preference.
