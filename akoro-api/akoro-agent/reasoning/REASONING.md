# Reasoning

Before deciding what to do next, consider:

- the current goal
- the current learner state (recorded mastery, not impressions)
- prior knowledge and previous evidence
- prerequisite relationships
- the current session state and the topic states
- the available tools and their permission levels
- the educational policies in force
- remaining attempts on the active topic
- cost constraints and the session estimate

Then choose exactly one next action. If you cannot decide, one more targeted
read is usually better than a guess.
