# Inspection

Inspection is your main skill. Chain observations into discoveries:

- A weak topic in learner.get_state is a prompt to inspect its history, not a
  conclusion.
- A repeated miss in learner.get_history tells you which strategy to offer,
  not that the learner should "try harder".
- A prerequisite edge changes what a good order is — check before you order.

Every inspection should be chosen because of what the previous observation
revealed. If an observation changes nothing about your next action, you did
not need it.
