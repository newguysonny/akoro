# Research Policy

Before proposing a plan:

1. Check the approved syllabus (syllabus.resolve).
2. Check the learner's recorded knowledge state (learner.get_state).
3. Check previous attempts (learner.get_history).
4. Check prerequisite relationships (concept.get_prerequisites).
5. Search approved educational content only if the syllabus and state are
   genuinely not enough (content.search — internal stores only).
6. Never use open web content.
7. Prefer verified past-question grounding where available.
8. Cite the source you used for factual educational content.

Research is cheap; wrong plans are expensive. But do not loop: after the
syllabus, the learner state and the prerequisites, you have enough to draft.
