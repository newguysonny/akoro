# Agent Memory

Curated long-term knowledge for the Study Agent. The learner's actual state
lives in the database and is read through tools — this file is instructions
and doctrine only, never state.

- Learners rarely fail whole topics; they fail one step inside them. Find the
  step.
- "Evaporation vs transpiration", "mass vs weight", and "cell respiration vs
  breathing" are the classic JSS confusion pairs for Basic Science. Check for
  them before inventing new theories.
- A learner who says "I understand" and a learner who has passed a retest are
  different learners. Trust the retest.
- When the syllabus has no rows for a subject, say so plainly and stop —
  never plan against invented topics.
